Intercropping in TZA LSMS - ISA wave 4

Starting by exploring the Maize legume intercropping in Tanzania employing LSMS-ISA data. The employed data is from wave 4 which has been collected in 2014-2015.

a) Wave 4: Long Rainy Season

setwd("D:/WORK/LEG4DEV/leg4dev")

cropdata <- read_dta("data/tza/tza_wave4/ag_sec_4a.dta") |> 
  select("y4_hhid", "plotnum", "zaocode", "zaoname", "ag4a_01", "ag4a_02", "ag4a_03", "ag4a_04", "ag4a_05", "ag4a_06") |> 
  rename(intercrop = ag4a_04) %>%
  filter(!is.na(zaocode))  # Remove rows with missing zaocode
# Filter for plots where maize (zaocode == 11) was grown
maize_data <- cropdata |> 
  filter(zaocode == 11)

# Count of unique households cultivating maize
length(unique(maize_data$y4_hhid))
[1] 1430
# Count of unique households with at least one intercropped maize plot
length(unique(maize_data$y4_hhid[maize_data$intercrop == 1]))
[1] 1056
# Total number of maize plots that were intercropped
sum(maize_data$intercrop == 1, na.rm = TRUE)
[1] 1432
# Define the legume zaocodes
legume_codes <- c(31, 32, 33, 34, 35, 36, 37, 43, 47)

# Get all maize intercropped plots
maize_intercropped_plots <- maize_data |> 
  filter(intercrop == 1) |> 
  select(y4_hhid, plotnum) |> 
  distinct()

# From the full cropdata, find all crops that were planted on the same plots as intercropped maize
maize_anyintercrop_plots <- cropdata |> 
  semi_join(maize_intercropped_plots, by = c("y4_hhid", "plotnum"))

Let’s check if legumes were planted alongside maize on those same plots:

# Filter for plots with either maize (zaocode == 11) or legumes
maize_legume_plots <- maize_anyintercrop_plots |> 
  filter(zaocode %in% c(11, legume_codes)) |> 
  group_by(y4_hhid, plotnum) |> 
  summarise(
    has_maize = any(zaocode == 11),  
    has_legume = any(zaocode %in% legume_codes),  
    .groups = "drop"
  ) |> 
  filter(has_maize & has_legume)  # Only keep rows where both maize and legumes are present

# Get the unique households who intercropped maize with legumes
n_distinct(maize_legume_plots$y4_hhid)
[1] 736

Summary: During the Long Rainy Season of Wave 4, a total of 1,430 households cultivated maize. Among them, 1,056 households practiced intercropping on at least one of their plots, resulting in 1,432 intercropped plots. The remaining 374 maize-cultivating households did not practice intercropping. Of the intercropped plots, 736 households intercropped maize specifically with a legume crop.
